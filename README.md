# Roman Numeral Converter

A simple, clean web application that converts numbers to Roman numerals. Supports conversion for numbers between 1 and 3999.

[Live Demo](https://reyrove.github.io/roman-numeral-converter/)

## Features

- Instant number to Roman numeral conversion
- Supports numbers from 1 to 3999
- Input validation with helpful error messages
- User-friendly interface with responsive design
- Clear visual feedback on results

## How It Works

1. Enter a number between 1 and 3999 in the input field
2. Click the "Convert" button
3. The application will display the Roman numeral equivalent

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation

1. Create a new folder on your computer
2. Save the following files in that folder:
   - `index.html` (the HTML structure)
   - `styles.css` (the styling)
   - `script.js` (the JavaScript logic)
3. Open `index.html` in any modern web browser

## Usage Examples

| Input | Output |
|-------|--------|
| 1 | I |
| 4 | IV |
| 9 | IX |
| 58 | LVIII |
| 1994 | MCMXCIV |
| 3999 | MMMCMXCIX |

## Validation Rules

- Numbers less than 1: Shows error message
- Numbers greater than 3999: Shows error message
- Empty input: Shows error message
- Invalid input: Shows error message
